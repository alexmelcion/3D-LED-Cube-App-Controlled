# 3D LED Cube (App-Controlled)

This repository contains the source code and application files for a custom-built 3D LED Cube, developed as my High School Research Project (Treball de Recerca). 

## ⚙️ Hardware / Microcontroller
* **Controller:** Arduino Uno R3
* The C/C++ code for the microcontroller can be found in the `Arduino_Code` folder. It handles the multiplexing and renders the 3D animations.

## 📱 Mobile App (App Inventor & Web Technologies)
The cube is controlled via a custom Android application. 
* The App Inventor project file (`.aia`) and related web assets (HTML, CSS, JS) are located in `Android_App_Source`.
* The compiled Android executable is available in the `App_Build` folder (`.apk`).
* The `App_Assets` folder contains the standalone icons, images, and UI elements used in the app. They are included here so you can quickly preview the visual design and graphical interface without needing to import the project file.
